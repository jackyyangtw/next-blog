# Web 版轉 App 版進度

最後更新：2026-09-04

本文件以 Web 前台的讀者功能為基準，追蹤行動版的實作進度。

## 不納入 App 的功能

- [x] Sanity Studio（`/studio`）
- [x] 文章新增、編輯、刪除與發布
- [x] 草稿預覽與內容審核流程
- [x] Sanity webhook 與 Next.js revalidate

以上能力維持由 Web 後台處理，App 僅提供內容閱讀與帳號相關功能。

## 基礎架構

- [x] `apps/mobile` Expo 專案
- [x] Expo Router 檔案式路由
- [x] React Native Paper 元件與全域 Provider
- [x] 共用 `@jacky-dev/design-tokens` 設計 token
- [x] 依系統模式啟動的深色／淺色主題
- [x] App 內手動切換深色／淺色模式
- [x] 繁中／英文介面與 mock 文章內容切換
- [x] 設定頁：深淺色與語言選擇
- [x] 主題與語言偏好跨重整／重開 App 保存
- [x] Safe Area 與 Web 匯出支援

## 路由與導覽

- [x] `/` 首頁

- [x] `/auth` 登入頁入口
- [x] `/user` 個人資料與收藏入口
- [x] 底部導覽：首頁、文章、我的
- [x] 從首頁／文章列表導向文章詳情
- [x] 從個人頁導向登入頁

## 後續建議順序

1. 建立 App 專用 API client，先完成文章列表與詳情的正式資料來源。
2. 實作 Portable Text 渲染，補齊 Web 文章閱讀體驗。
3. 導入 OAuth deep link、工作階段保存與收藏功能。
4. 最後完成搜尋、回饋、相關文章與離線體驗。
